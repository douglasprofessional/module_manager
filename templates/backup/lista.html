{# Nota explicativa sobre os dois tipos de backup #}

Backup por módulo gera um fixture Django (.json.gz), restaurável por linha de comando com manage.py loaddata. Backup completo gera um .zip com os dados de todos os módulos, o dump nativo do banco e, opcionalmente, a pasta de mídia.

A restauração não é feita pela interface (por segurança): use a CLI, conforme o README.
