{# Explicação dos tipos de backup #}

{% texto "backup.novo.tipos_titulo" %}

Módulo: exporta os dados de um app como fixture Django (.json.gz). Restaure com manage.py loaddata após descompactar.

Completo: gera um .zip com o fixture de todos os módulos, o dump nativo do banco e, se marcado, a pasta de mídia.

Migração EasyPanel: pacote pronto para transferir a plataforma a outro servidor EasyPanel — inclui o dump do banco, a mídia, o fixture, um .env.exemplo e o passo a passo de restauração (MIGRACAO-EASYPANEL.md).

A restauração não é feita pela interface (por segurança). Os arquivos ficam num diretório privado; o download passa por uma view protegida.
